# kpi_settlement_reports

Автоматизована система розподілу студентів по гуртожитках на основі рейтингових балів у Студмістечко КПІ ім. Ігоря Сікорського (https://settlement.kpi.ua/ratings), пріоритетів та гендерних квот. Скрипт отримує дані з API, проводить симуляцію розселення та генерує детальний Excel-звіт із графіками, статистикою та кольоровою розміткою вкладок.

## Можливості

- **Розумний розподіл:** Враховує рейтинговий бал, наявність пільг, бонусів та черговість пріоритетів.
- **Гендерне квотування:** Роздільне квотування для чоловічих, жіночих та вільних (унісекс) місць.
- **Два режими заселення:**
  1. Спочатку заповнюються виділені гендерні місця, потім — вільні кімнати.
  2. Спочатку заповнюються вільні кімнати, потім — залишки гендерних місць.
- **Детальний Excel-звіт:**
  - Загальна статистика з діаграмами (розподіл балів, факультети, пільговики).
  - 🟢 Світло-зелені вкладки — гуртожитки, де ще є вільні місця.
  - 🔴 Світло-червоні вкладки — повністю заповнені гуртожитки.
  - 🟡 Світло-жовта вкладка — загальна статистика по кампанії.
  - 🔵/🟣 Окремі аркуші для відмов та тих, кому не вистачило місця (світло-сині та фіолетові вкладки).

```bash

cd kpi_settlement_reports
```

2. Встанови необхідні залежності. Для роботи скрипта потрібні requests, pandas та xlsxwriter:
```Bash

```

## Налаштування (Конфігурація)
Усі основні налаштування знаходяться на початку файлу скрипта. Перед запуском ти можеш змінити їх під свої потреби:
- ROOM_CAPACITY (int) — максимальна місткість однієї унісекс кімнати (за замовчуванням: 3).
- FILL_MODE (1 або 2) — логіка заповнення (1: спочатку гендерні квоти; 2: спочатку унісекс кімнати).
- DORM_CAPACITIES (dict) — словник з місткістю кожного гуртожитку. Формат:
```
Python
{ номер_гуртожитку: {'male': кількість, 'female': кількість, 'unisex': кількість} }
```

## Використання
Просто запусти Python-скрипт. Він автоматично стягне дані по API та згенерує файл settlement_results.xlsx.
```
Bash
python main.py
```
Після виконання в консолі з'явиться короткий звіт про кількість виділених та заселених місць, а в папці проєкту з'явиться готовий Excel-файл.

## Структура Excel-звіту
- Статистика: Зведені таблиці та кругові/стовпчасті діаграми.
- Гурт. {Номер}: Поіменні списки заселених студентів із зазначенням балів (бонуси підсвічуються), факультету та пріоритету.
- Не пройшли: Список студентів, яким не вистачило місць у вибраних ними гуртожитках.
- Відмови: Список заявок зі статусом denied.

## Технології
- Python 3.x
- Pandas — обробка даних та створення датафреймів.
- XlsxWriter — генерація Excel-файлів, форматування клітинок, створення графіків та фарбування вкладок.
- Requests — HTTP-запити до відкритого API.
Розроблено для автоматизації та аналізу процесів поселення.
